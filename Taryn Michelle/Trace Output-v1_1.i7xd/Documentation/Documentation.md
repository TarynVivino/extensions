Chapter: Purpose

My system for writing messages for 'tracing' code execution during development and debugging, and controlling when, how, and where those messages are displayed. 

Section: Version History

Version 1: Preliminary working version, not publicly released

Version 2: Works with Inform 10.1 (release) as well as current builds of 10.2 (as of April 11, 2026)

Simplified command-line control, priority and verbose message filtering, added documentation and sample code.
